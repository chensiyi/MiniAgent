核心版本

  • 油猴脚本版（Tampermonkey）——安装一次，配置跨站自动统一。
  • basement 核心库——IIFE 全局 MiniAgent 内核（书签版 / 油猴版共用）。

⚠️ 书签版的存储位于固定 CDN 源 iframe 内的 localStorage；浏览器对跨源 iframe 的存储按嵌入站点分区， 因此在不同网页上的工具开关相互独立、不跨站共享。需要跨站统一请使用油猴版。详见 存储说明。
